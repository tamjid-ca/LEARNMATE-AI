# LearnMate Engineering Plugin

Workspace-scoped Antigravity plugin providing project rules, specialized engineering skills, and subagent role definitions for **LearnMate AI**.

## Contents

- `rules/AGENTS.md` — Always-on workspace rules enforcing state protocol, SRS compliance, and security invariants.
- `skills/frontend-engineering/SKILL.md` — Next.js App Router, Tailwind CSS, shadcn/ui, theming, and bilingual (Bangla/English) UI guidelines.
- `skills/backend-engineering/SKILL.md` — Route Handlers, Controller/Service/Repository boundaries, Zod validation, and RBAC rules.
- `skills/mongodb-engineering/SKILL.md` — Mongoose connection pooling, schema patterns, indexing, ownership isolation, and pagination.
- `skills/ai-integration/SKILL.md` — OpenRouter gateway, model routing, structured Zod output validation, RAG grounding, and rate limiting.
- `skills/security-review/SKILL.md` — Auth, RBAC, NoSQL injection prevention, upload validation, and prompt-injection defense checklist.
- `skills/testing-quality/SKILL.md` — Vitest unit/integration and Playwright E2E verification gates.
